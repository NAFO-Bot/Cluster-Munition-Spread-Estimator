Cluster Munition Spread Estimator

Model

Ground footprint width is estimated using:

Spread Width = 2 × h × tan(θ / 2)

  • h = release altitude
  • θ = total dispersion angle

This is an idealized geometric approximation. Real-world spread depends on:

  • wind drift
  • release velocity
  • camera perspective distortion
  • submunition aerodynamics
